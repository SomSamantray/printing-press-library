# Gemini Notebook — UI → RPC Map

**Date:** 2026-07-21  
**Transport:** `POST https://notebooklm.google.com/_/LabsTailwindUi/data/batchexecute`  
**Response format:** Google XSSI prefix `)]}'` then JSON frames  
**Auth:** Google session cookies (`.google.com`); CSRF via `at` token in POST body  
**Build fingerprint:** `bl=boq_labs-tailwind-frontend_20260719.02_p0` (observed 2026-07-21)

Query parameters on every batchexecute call:
- `rpcids` — operation identifier (may be comma-separated for batch)
- `source-path` — current page path (e.g. `/notebook/{uuid}`)
- `bl` — frontend build label
- `f.sid` — session id
- `hl` — locale
- `_reqid` — monotonic request counter
- `rt=c` — response type

POST body fields: `f.req` (JSON payload), `at` (CSRF token).

Async artifact status: long-poll via `signaler-pa.clients6.google.com/punctual/multi-watch/channel`.

## Implementation notes for Go client

1. **Session bootstrap:** Load notebook page HTML to extract `f.sid`, `at`, and `bl` before first batchexecute.
2. **Batching:** UI sends multiple single-rpcid requests in parallel on load; client may batch or parallelize similarly.
3. **Polling:** Studio artifacts require `signaler` long-poll or repeated `cFji9`/`gArtLc` until terminal state.
4. **No cookies in artifacts:** Strip `Cookie`, `at`, and session tokens from all saved discovery files.
5. **Build label drift:** `bl` changes with Google deploys; doctor should detect 400/403 and prompt re-sniff.
